## 🚀 Quick Start

### 1. Download

```bash
git clone https://github.com/jvieranieves54-alt/j5-trading-strategy.git
cd j5-trading-strategy
```

### 2. Installation

1. Download the `.mq5` files from the `/mql5` folder
2. Open your MetaTrader 5 terminal
3. Click on **File → Open Data Folder**
4. Navigate to **MQL5** folder
5. Create or paste files in:
   - **Experts** folder for Expert Advisors (`.mq5`)
   - **Indicators** folder for indicators (`.mq5`)
6. Restart MetaTrader 5
7. In MetaTrader, compile the `.mq5` files if needed

### 3. Apply to Chart

1. Open a chart in MetaTrader 5
2. Go to **Insert → Indicators**
3. Select your desired indicator
4. Drag and drop an Expert Advisor onto the chart
